07

MCP Tools

Connect an agent to a remote MCP tool server in four lines — allowlist the tools to keep the payload small, and listTools() to find the names.

php
$discovered = $agent->registerMcpServer($mcpClient);
$agent->enableActivityLogging();

$answer = $agent->chat("Repository: facebook/react\nQuestion: What does this repo do?");

// Not sure which names? Ask the server — registers nothing:
foreach ($mcpClient->listTools() as $tool) { echo $tool['name'], "\n"; }

// Register only the tools you need — each one costs a schema on every turn:
$discovered = $agent->registerMcpServer($mcpClient, allowlist: ['ask_question']);

10

Stateful Tools

An agent that reads and mutates an inventory — a tool with state.

php
public function order(string $id, int $qty): string {
        if ($this->products[$id]['stock'] < $qty) return "Error: Insufficient stock.";
        $this->products[$id]['stock'] -= $qty;   // <-- the mutation
        return "Success: Ordered $qty of {$this->products[$id]['name']}.";
    }
